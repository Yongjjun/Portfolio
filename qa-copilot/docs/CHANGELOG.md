# Changelog

## v0.1.0 - Keyword-based Rule Detector

### 구현
- 요구사항 텍스트 입력
- QA Rule Keyword Matching
- 적용 가능한 Rule 출력

### 현재 지원 Rule
- Validation
- Boundary Value
- Equivalence Partition
- Negative Test
- Business Rule
- State Transition
- Regression
- Platform
- Accessibility
- Security

- 단순 키워드 존재 여부에 의존
- 문맥을 이해하지 못함
- 동일한 단어가 다른 의미로 사용되는 경우 오탐 가능
